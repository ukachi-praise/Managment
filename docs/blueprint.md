# **App Name**: JustVision Kiddies School Database & Result Management System

## Core Features:

- User Authentication: Secure role-based login (Admin, Teacher) with password reset/change functionality.
- Classroom and Subject Management: Admin creates/manages classrooms and subjects, assigning subjects to classrooms.
- Result Input: Teachers enter CA1, CA2, CA3, and Exam scores per student, per subject.
- Automated Grade Calculation: System automatically calculates total scores, grades, and remarks based on predefined grade mapping.
- Soft Skill Auto-Generation: AI tool to automatically generate soft skill scores and remarks based on academic performance and attendance.
- Result Template Builder: Admin uses drag-and-drop interface to create and customize result templates (JSON + file storage).
- Bulk PDF Export: Admin generates and exports result PDFs per student or in bulk per class, packaged into a ZIP archive.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to create a calm and trustworthy atmosphere suitable for an educational environment.
- Background color: Very light blue (#F0F8FF), a desaturated version of the primary color to create a subtle backdrop.
- Accent color: Pale cyan (#90e0ef), analogous to light blue to highlight important interactive elements.
- Body and headline font: 'PT Sans', a humanist sans-serif providing a modern, clean, yet slightly warm aesthetic.
- Clean, tabular layouts for displaying student information and results, ensuring readability and easy navigation.
- Use clear, simple icons to represent different actions and sections within the platform, such as user management, subject management, and report generation.
- Subtle transitions and animations to provide feedback and improve user experience, like loading animations when generating reports or saving data.
